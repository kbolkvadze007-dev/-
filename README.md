MediCare — კლინიკის მართვისა და ონლაინ ჩაწერის სისტემა

პროექტის მიმოხილვა

MediCare არის კლინიკის მართვის ვებპლატფორმა, რომლის მიზანია პაციენტებისთვის ექიმების მოძიებისა და კონსულტაციაზე ჩაწერის პროცესის გამარტივება.

პლატფორმა მომხმარებლებს საშუალებას აძლევს, დაათვალიერონ ექიმების კატალოგი, მოძებნონ სპეციალისტები სხვადასხვა მიმართულებით, გაეცნონ ექიმების პროფილებს და ონლაინ დაჯავშნონ ვიზიტი.

პროექტის ფარგლებში განხორციელებულია ონლაინ ჩაწერის ფუნქციონალი, რომელიც მოიცავს ექიმის არჩევას, ვიზიტის თარიღისა და დროის შერჩევას, ფორმის შევსებასა და მონაცემების ვალიდაციას.

გუნდის წევრები და როლების გადანაწილება



სტუდენტი 1 : ქეთი ბოლქვაძე — როლი: ექიმების კატალოგი, ექიმების მონაცემების ჩატვირთვა და პროფილების მართვა.

სტუდენტი 2: ვერიკო ნაკევხრიშვილი — როლი: ონლაინ ვიზიტის დაჯავშნის სისტემა, კალენდარი, დროის არჩევა და Formik/Yup ფორმების ვალიდაცია.




პროექტის ლოკალურად გაშვების ინსტრუქცია

1. რეპოზიტორიის კლონირება

git clone https://github.com/kbolkvadze007-dev/-.git
cd Management-System-Student2
git checkout feature/student-2-booking

2. დამოკიდებულებების ინსტალაცია

npm install

3. პროექტის გაშვება დეველოპმენტ რეჟიმში

npm run dev

4. პროექტის Build

npm run build

## მნიშვნელოვანი შენიშვნა
პროექტში გამოყენებულია დემო ექიმები და სატესტო პროფილის მონაცემები. კლინიკების სახელები, რეიტინგები, ფასები და განრიგი რეალურ სამედიცინო შეთავაზებად არ უნდა ჩაითვალოს. რეალურ სერვისად გამოსაყენებლად საჭიროა backend/API და მონაცემების გადამოწმება.

## ონლაინ ჩაწერის ფუნქცია (Student 2)

ექიმის პროფილიდან შესაძლებელია ონლაინ ვიზიტის დაჯავშნის ფორმის გახსნა. ფორმა მოიცავს პაციენტის მონაცემებს, თარიღის არჩევას, ექიმის სამუშაო დღეების შემოწმებას, დროის სლოტებსა და მიმართვის მიზეზს.
